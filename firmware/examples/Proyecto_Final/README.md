# Proyecto_Final
Este proyecto consiste en un sensor de temperatura con un termistor para calcular la frecuencia respiratoria. El código calcula la frecuencia respiratoria y la muestra por la UART.
El proyecto corresponde al trabajo integrador de Electrónica Programable del 2do cuatrimestre de 2024, de la carrera de Bioingeniería de la FIUNER.
Autoras: Battauz Barón, Antonella y Calvo, Manuela
